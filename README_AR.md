# استعادة قفل Android

تطبيق Android بسيط باللغة العربية يعرض معلومات الجهاز ويوفر روابط دعم رسمية لاستعادة الوصول.

## ما يفعله
- يعرض الشركة المصنّعة والطراز وإصدار Android.
- يختار صفحة الدعم حسب الشركة المعروفة.
- يفتح صفحات مساعدة Google والنسخ الاحتياطي.
- لا يحتاج إلى أذونات خاصة، ولا يحذف أي بيانات.

## ما لا يفعله
- لا يفتح PIN أو نمط الرسم أو كلمة المرور.
- لا يتجاوز شاشة القفل أو تشفير Android.
- لا يضمن استعادة البيانات التي لم تُنسخ احتياطيًا.

## البناء
1. ثبّت Android Studio على كمبيوتر.
2. افتح مجلد `AndroidLockRecovery` في Android Studio.
3. اسمح بمزامنة Gradle.
4. من قائمة Build اختر **Build APK(s)**.
5. ثبّت APK الناتج على جهاز Android.

المتطلبات: Android Studio حديث، وJDK المتوافق مع إصدار Android Gradle Plugin، واتصال إنترنت أثناء تنزيل أدوات البناء أول مرة.


## البناء التلقائي على GitHub Actions
بعد رفع ملفات المشروع إلى مستودع GitHub في الفرع `main`، سيبدأ البناء تلقائيًا عند كل push. ويمكن تشغيله يدويًا من تبويب **Actions** عبر **Build Android APK → Run workflow**. عند نجاح البناء، افتح تشغيل workflow ثم نزّل artifact باسم `AndroidLockRecovery-debug-apk`. يحتوي على APK تجريبي للتثبيت، وليس إصدارًا موقّعًا للنشر في متجر Play.
